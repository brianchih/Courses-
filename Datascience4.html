單元四：常見圖表陷阱與「話術」剖析（上）——軸線、時間與空間

軸線與時間切片的操控機制

圖表呈現的視覺比例，本質上由繪圖者的三項選擇所決定：軸線起點 (Baseline)、刻度比例 (Scale) 與時間窗範圍 (Time Window)。當這些變數被有心選擇時，同一份真實數據將導出截然相反的商業結論。

陷阱 01

截斷 Y 軸 (Truncated Axis)

柱狀圖（Bar Chart）柱子的高度正比於數值。若 Y 軸不從 0 開始，將會人為暴增視覺長度比例，將小幅差距誇大為數倍懸殊差距。

陷阱 02

雙 Y 軸 (Dual Y-Axes)

左右兩側的刻度均由作者任意指定，曲線與柱體的「交叉點」純屬視覺巧合，極易誤導讀者產生虛假的因果關聯。

陷阱 03

櫻桃採摘 (Cherry-picking)

刻意選擇景氣谷底作為比較基期（Base Year），或是只擷取短期暴跌的時間視窗，掩蓋長期真實的向上趨勢。

截斷 Y 軸的誇大倍率數學解析

設兩家公司真實數據分別為 $V_A = 45.1\%$ 與 $V_B = 17.6\%$（真實比例為 $45.1 / 17.6 \approx 2.56$ 倍）。若將 Y 軸截斷從 $y_{min} = 14\%$ 開始：

$$\text{視覺長度比} = \frac{V_A - y_{min}}{V_B - y_{min}} = \frac{45.1 - 14}{17.6 - 14} = \frac{31.1}{3.6} \approx 8.64 \text{ 倍}$$

原本僅有 $2.56$ 倍的真實獲利差距，在視覺上被無端誇大為 $8.64$ 倍，嚴重扭曲讀者的直覺認知。

雙 Y 軸替代方案：小多版分格圖 (Small Multiples)

雙 Y 軸圖表之所以危險，在於讀者無法在第一時間對比兩組不同單位的量化關係。

誠實的解決方案：使用「上下分格（Small Multiples）」展示。上圖展示金額絕對值（資本支出，十億美元），下圖展示百分比比率（資本支出佔營收比 %），並讓兩家公司共用同一比率刻度軸，即可一目瞭然高下。

Python 數據清理與繪圖規範

預防軸線與時間誤導的繪圖準則

使用 matplotlib / plotly 時必須確保：

  • • 柱狀圖：fig.update_yaxes(rangemode="tozero") 強制從 0 開始
  • • 折線圖：時間軸刻度必須保持等距 (Equal time intervals)
  • • 指數對比：標示基期年份（如以 2021 = 100 為基準）

Plotly 上下分格 (Subplots) 範例

使用 Python 替代雙 Y 軸的寫法：

from plotly.subplots import make_subplots
import plotly.graph_objects as go

fig = make_subplots(rows=2, cols=1, shared_xaxes=True)
fig.add_trace(go.Bar(x=years, y=capex), row=1, col=1)
fig.add_trace(go.Scatter(x=years, y=ratio), row=2, col=1)
fig.update_yaxes(range=[0, 60], row=2, col=1) # 共用刻度

軸線審查 Prompt Engineering (提示詞設計)

請 LLM 產出商業財報圖表時，可使用以下 Prompt 避免軸線與基期陷阱：

請作為商業財報視覺化專家，撰寫 Python / Plotly 程式碼。

【目標數據】: 台積電與聯電 FY2021-2025 淨利率與資本支出數據。
【設計原則 - 軸線與時間切片規範】:
1. 嚴禁使用雙 Y 軸 (Dual Y-axes)，請改用上下分格小多版 (Subplots)。
2. 若畫柱狀圖，Y 軸必須明確設定 range=[0, max_value]，嚴禁截斷 Y 軸。
3. 時間窗口規範：
   - 繪製股價或營收時，必須同時展示完整年度數據（如全年度 52 週），不得僅剪裁單月跌幅。
   - 若使用相對指數，必須於副標題清晰註明基期（如「以 2021 年為基期 = 100」）。
4. 圖表標題必須直接寫出誠實結論，並於圖末加上來源與 n 值說明。
對照組 01

FY2025 淨利率對比：台積電 vs 聯電

真實數據：台積電 45.1% vs 聯電 17.6% (真實差距為 2.56 倍)。

✕ 誤導畫法：截斷 Y 軸 (起點從 14% 開始)
視覺效果：柱子高度差距達 8.6 倍！大幅誇大差距。
✓ 誠實畫法：Y 軸從 0% 開始
視覺效果：真實反映 2.56 倍的比例差距。
對照組 02

台積電 2025 年股價走勢：短看下跌 vs 遠看大漲

同一份 2025 年週收盤價數據，挑選不同的時間窗口會得到完全相反的解讀。

✕ 誤導畫法：刻意剪裁 1 月至 4 月時間窗
結論導向：「台積電三個多月暴跌 21%！」造成恐慌。
✓ 誠實畫法：放回 2025 全年時間窗
結論導向：「放回全年看，台積電 2025 全年大漲 44%。」
