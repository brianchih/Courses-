單元五：常見圖表陷阱與「話術」剖析（下）——視覺幾何與統計分布

幾何縮放與統計平均數的失真機制

除了軸線與時間切片外，圖表作者最常用於扭曲事實的手法是維度錯置（用半徑表達面積）與資訊壓縮（只看平均數而掩蓋離群值）。瞭解其背後的幾何原理與統計失真機制，能幫助我們識破精美的簡報話術。

陷阱 01

幾何維度放大 (Radius Scaling)

人類視覺感知的形狀大小是「面積」，若作者將數值對應至圓形的「半徑」，視覺面積會產生二次方（平方）暴增，導致第一名看起來巨大無朋。

陷阱 02

只看平均數 (Grand Mean Fallacy)

極端離群值（如 Apple ROE 達 152%）會嚴重大幅拉高整體平均數，掩蓋了兩群樣本實質大量重疊的真實分佈現況。

經濟學洞察

誤導圖表為何不消失？

源自三項經濟學因素：資訊不對稱（繪圖者知道軸點/讀者不查）、注意力稀缺（讀者只看標題與形狀）與誘因不一致（公司法說會誘因）。

氣泡圖面積與半徑的幾何算式

設兩家公司市值為 $V_1 = 5,245$ (NVIDIA) 與 $V_2 = 2,189$ (台積電)，實際市值比例為 $V_1 / V_2 \approx 2.40$ 倍。

$$\text{若直接令半徑 } r \propto V \implies \text{視覺面積比 } \frac{A_1}{A_2} = \left(\frac{r_1}{r_2}\right)^2 = \left(\frac{5245}{2189}\right)^2 \approx 5.74 \text{ 倍}$$

原本僅有 $2.40$ 倍的差距被誇大為 $5.74$ 倍。誠實的氣泡圖半徑必須開平方根換算：$r \propto \sqrt{V}$，方能確保視覺面積正比於真實數值。

平均數與離群值（Outliers）拉抬計算

在美國 22 家樣本公司中，單一極端值 Apple (ROE = $152\%$) 對總平均數的拉抬效應可表達為：

$$\Delta \bar{X} = \frac{\text{ROE}_{\text{Apple}} - \bar{X}_{\text{others}}}{n} = \frac{152\% - 25.8\%}{22} \approx 5.74 \text{ 個百分點}$$

單單 Apple 一家公司就把美國平均 ROE 從 $25.8\%$ 人為抬升至 $31.5\%$。若改觀察中位數（美國 $27\%$, 台灣 $12\%$）與個體散佈圖，便會發現兩國大多數公司的 ROE 其實高度重疊。

Python 分佈圖形與氣泡幾何繪圖規範

正確氣泡圖與分佈圖寫法

使用 matplotlib / plotly 繪圖時：

  • • 氣泡大小：plt.scatter(s=np.sqrt(values)) 以確保面積正比
  • • 展示分佈：選用 Strip Plot + Box Plot 展示真實點陣
  • • 標示統計量：同時畫出「中位數 (Median)」線段標記

Plotly 個體散佈圖 (Strip Plot) 範例

畫出每一家公司點陣避免平均數陷阱：

import plotly.express as px

# 使用 box 搭配 points="all" 呈現全部個體點陣
fig = px.box(df, x="country", y="roe", points="all",
hover_data=["company_name"])
fig.update_traces(boxpoints='all', jitter=0.3)
fig.show()

請作為資料視覺化與統計學專家，撰寫 Python / Plotly 程式碼。

【目標數據】: 台灣 (n=48) 與美國 (n=22) 半導體公司 FY2025 ROE 數據。
【設計原則 - 分佈與幾何規範】:
