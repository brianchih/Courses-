單元一：視覺化的本質——圖會說話，也會說謊

視覺編碼（Visual Encoding）與映射函數

資料視覺化的本質，是將抽象的數據空間（Data Domain $D$）透過特定對應規則，映射至人類視覺認知感知空間（Visual Domain $V$）的過程。我們可以將視覺化過程定義為一個映射函數：

$$f: D \longrightarrow V \quad \text{where} \quad D = \{d_1, d_2, \dots, d_n\}, \: V = \{v_1, v_2, \dots, v_m\}$$

視覺變數包含位置 (Position)、長度 (Length)、角度 (Angle)、面積 (Area)、色相 (Hue) 與色彩彩度 (Saturation)。不同視覺編碼對於精確度（Accuracy）的認知等級不同，其中「位置」與「長度」精確度最高，而「面積」與「色彩」則容易產生視覺偏差。

幾何放大陷阱：半徑 vs 面積

當我們使用氣泡圖（Bubble Chart）代表數值大小時，若誤用數值直接映射為圓的半徑 ($r$)，而非面積 ($A$)，將會造成嚴重的感官誇大效果：

$$A = \pi r^2 \implies \text{若 } r_2 = k \cdot r_1, \text{ 則 } A_2 = k^2 \cdot A_1$$

例如：當數值僅成長為 $2$ 倍時，若半徑放大 $2$ 倍，視覺面積將暴增為 $2^2 = 4$ 倍，形成誤導性視覺效果。誠實的畫法應取平方根運算：

$$r_{\text{correct}} = r_0 \times \sqrt{\frac{V_i}{V_0}}$$

馬歇爾（Marshall）產業群聚經濟學

同一份資料集中，廠商為什麼傾向「擠在一起」？馬歇爾（Alfred Marshall）提出產業群聚的三大理由：

  • 01 人才池 工程師轉職不必搬家，企業招募迅速且員工承擔風險低。
  • 02 專屬供應商 設備、零組件與維修資源就近支援，交期以小時而非以週計算。
  • 03 知識外溢 餐會、球場與非正式網絡中，未記載於合約的技術訊息流通極快。

誠實圖表 Prompt Engineering (提示詞設計)

使用 LLM 生成視覺化程式碼時，可遵循「三拍子原則」設計提示詞範本：

請作為資料視覺化專家，撰寫 Python / Plotly 程式碼。

【目標數據】: 91 家半導體公司總部經緯度與財報數據。
【設計原則 - 三拍子規範】:
1. 一個問題：主標題直接寫出數據結論（非變數名稱）。
2. 一張圖：採用灰底配色，僅對重點項目使用一個單一強調色。
3. 一個陷阱標記：
   - Y 軸必須從 0 開始；若為氣泡圖，半徑必須進行平方根換算 (r = sqrt(value))。
   - 頁腳必須清晰註明：數據來源、時間範圍、統計樣本數 n、計算口徑與缺失值說明。
4. 提供誠實版本與誤導版本的對照註解。
