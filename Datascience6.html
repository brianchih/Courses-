單元六：實戰指南與視覺化地圖（FT Visual Vocabulary）

FT Visual Vocabulary：一份資料，九種提問

英國《金融時報》（Financial Times）團隊開發的 **Visual Vocabulary** 核心觀念為：**「繪圖前，先決定你想讓讀者看懂哪一種資料關係，再選擇對應圖表。」** 切忌先選了圖表樣式才塞入資料。

01 離散差異 (Deviation)
對比基準值與正負差距（如 WSTS 預測）
02 相關性 (Correlation)
兩或多個變數間的關聯（如研發比 vs 毛利率）
03 排序 (Ranking)
位置與名次先後（如半導體市值排行榜）
04 分佈 (Distribution)
數值的離散與集中趨勢（如各族群淨利率箱形圖）
05 隨時間變化 (Change over Time)
時間序列演變趨勢（如 IC 設計群 5 年成長）
06 量的比較 (Magnitude)
絕對數值大小比較（如台積電資本支出 vs 研發）
07 部分與整體 (Part-to-whole)
總體結構佔比（如 Treemap 矩陣樹圖）
08 地理空間 (Spatial)
空間分佈與經緯度地圖（如各國營收地圖）
09 流向 (Flow)
資金、營收或節點的流動關係（如桑基圖）

皮爾森相關係數 (Pearson $r$) 算式

在繪製「相關性 (Correlation)」散佈圖時，趨勢線與相關係數算式如下：

$$r = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^n (y_i - \bar{y})^2}}$$

例如：台灣半導體公司研發費用佔營收比與毛利率為弱正相關 ($r = 0.31$)，且需於頁腳強調**「相關不代表因果關係」**。

讀圖者 5 大檢查表 (Checklist)

下次看到任何商業或新聞圖表，養成先問 5 個問題的習慣：

  • 01軸從哪裡開始？ 長條圖不從 0 開始就是在人為放大差距。
  • 02期間與基期誰選的？ 換個起點或終點，結論還成立嗎？
  • 03看到的是平均還是全部？ 是否隱藏了極端離群值？
  • 04單位與口徑一致嗎？ 是否混用了匯率、名目 vs 實質？
  • 05誰被遺漏了？ 樣本選取是否存在倖存者偏差？

三拍子繪圖框架與課程評量設計

誠實圖表製作「三拍子」原則

每一張圖表均遵循以下結構製作：

  • • 1. 一個問題：主標題直接寫出「結論」，不寫變數名稱。
  • • 2. 一張圖：灰底配色加上單一強調色；單位、n 值寫在圖上。
  • • 3. 一個陷阱：註明該圖型最容易誤導處（軸、基期、半徑）。

課程評量與期末專題設計

視覺化實戰能力考核維度：

  • • 平時作業 (30%): 9 大系列圖表實作與 Python 碼
  • • 期中改圖 (20%): 找出媒體誤導圖、說明並畫出誠實版
  • • 期末專題 (40%): 自選產業做 6-8 張圖的 Data Story
  • • 課堂參與 (10%): 課堂投票與找圖分享

全能誠實視覺化 Prompt Engineering (提示詞設計)

綜合本課程所有單元的全能誠實圖表 Prompt 範本：

請作為資料視覺化專家，依據 FT Visual Vocabulary 規範，撰寫 Python / Plotly 程式碼。

【目標數據與關係類型】:
1. 請確認數據關係類型（選擇：離散差異 / 相關性 / 排序 / 分佈 / 時間變化 / 量的比較 / 部分與整體 / 空間 / 流向）。
2. 選用最佳圖型（例如：相關性選用 Scatter + Trendline；部分與整體選用 Treemap）。

【設計原則 - 誠實視覺化三拍子】:
- 主標題：寫出數據結論（例：「台積電資本支出是研發的 5.2 倍」），副標題標明變數與單位。
- 色彩視覺：整體採用灰底 (#f8fafc) 與灰色點/柱，僅對重點項目塗上一個強調色 (#2563eb)。
- 嚴格防偽防誤導標記：
  - 長條圖 Y 軸強制 range=[0, max]。
  - 氣泡圖大小強制對應平方根 (r = sqrt(value))。
  - 散佈圖若包含離群值，需標示點名與中位數。
- 頁腳標註：註明數據來源、時間範圍、樣本數 n、匯率口徑與限制說明。
